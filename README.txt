OMNIX CLAN — сайт для GitHub Pages

Файлы:
- index.html — главная
- rules.html — правила
- administration.html — администрация
- activity.html — активность
- rests.html — ресты
- schedule.html — расписание съёмок
- shop.html — магазин Астралов
- assets/style.css — оформление и анимация фона
- assets/omnix-angel-demon-banner.png — главный баннер (если включён в архив)

Публикация на GitHub:
1. Распакуйте архив.
2. Откройте репозиторий omnix-clan-rules → Code → Add file → Upload files.
3. Загрузите ВСЁ содержимое папки omnix_clan_site: все HTML-файлы и папку assets.
4. Commit changes.
5. Settings → Pages → Deploy from a branch → main → /(root).
6. Подождите несколько минут.

Важно: index.html должен лежать прямо в корне репозитория, а не внутри дополнительной папки.
